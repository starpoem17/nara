# 24개 feature 법령 판단 기준

버전: `legal-criteria-v1-draft` · 대회 기준일: 2026-07-27 · 작성일: 2026-09-10

제공 항목표·법령패키지만 사용. dev_labels.csv 및 개별 공고의 정답을 기준 작성에 사용하지 않음.

이 문서는 모델에 추가하는 기준과 동일한 JSON에서 생성했다. 조문 요약과 대회 feature의 판정 해석을 구분한다. 공식 정답 기준이 확인되지 않은 부분은 검토 메모에 남겼다. 이번 작업에서는 추가 추론이나 정확도 평가를 실행하지 않았다.

## 공통 판단 순서

1. 아래는 대회 제공 법령패키지와 항목표(2026-07-27)를 요약한 판정 기준 초안이다. 법령 원문 전체나 공식 정답 해석을 대체하지 않는다. 외부 법령·기억에 의존한 수치를 추가하지 않는다.
2. 적용 조건 → 의무 또는 금지 → 공고의 실제 자격/누락 → 허용 예외 순서로 판단한다. 모르는 사실·예외를 만들어 0 또는 1의 근거로 쓰지 않는다. 적용법·금액·제품 지정·예외가 불명확하면 제공 법령을 RAG로 확인한다. 검색 실패는 비해당 증명이 아니다.
3. 추정가격(부가세 제외), 예산(부가세 포함 여부 확인), SW 사업금액(부가세 포함)을 구별한다. 세액 구성이 확인되지 않으면 예산을 무조건 1.1로 나누지 않는다. T의 미만은 <T, 이상은 ≥T다. v3의 항목표/조문 충돌은 해당 검토 메모를 따른다.
4. 국가계약법4조의 물품·용역 고시금액은 동봉 국가고시 제1호 가목의 2.3억원이다. 이 금액과 지방 지역제한 상한, 공기업·준정부기관 국제입찰 금액은 다른 기준이다.
5. 경쟁제품을 먼저 분류한 후 v10~13과 비경쟁 일반제품 v14~18의 분기를 고른다. 세부품명번호·제품 범위·예외를 CSV/HWPX와 대조한다. 일반제품 우선조달 조문은 물품뿐 아니라 용역도 대상으로 한다. 공사에 일괄 적용하지 않는다.
6. 부재탐지(v10·v11·v16·v18·v20)는 적용 의무가 확정된 뒤 제공된 모든 문서에서 동등한 요건까지 확인한다. 다른 항목은 단순 문구 부재만으로 위반을 만들지 않는다. 요약 법령을 제출 근거문구로 인용하지 않는다.

### v1 · 참가자격 특정기관 제한

**적용 조건:** 참가 가능한 업체·기관의 종류를 제한하는 공고.

**위반으로 판단하는 경우:** 법적 근거 없이 특정 기관·기관 유형만 참가시키거나 계약 이행과 무관한 기관 자격을 요구한다.

**예외와 혼동 방지:** 법령상 필요한 면허·등록, 적법한 제한경쟁 사유는 제외. 발주기관 이름의 단순 표기는 제한이 아니며 특정 발주기관의 과거 실적 요구는 v4에서 별도로 검토.

**확인한 근거:** [국가령 제12·21조](<../data/법령패키지/법령/국가를 당사자로 하는 계약에 관한 법률 시행령.txt>); [지방령 제13·20조](<../data/법령패키지/법령/지방자치단체를 당사자로 하는 계약에 관한 법률 시행령.txt>); [국가규칙 제17조](<../data/법령패키지/법령/국가를 당사자로 하는 계약에 관한 법률 시행규칙.txt>); [지방규칙 제17조](<../data/법령패키지/법령/지방자치단체를 당사자로 하는 계약에 관한 법률 시행규칙.txt>)

**위반으로 판단하는 경우:** 해당 금액에서 수행·납품 실적을 입찰 또는 제안서 접수의 필수조건으로 요구한다.

### v3 · 실적제한 1배수 이상

**적용 조건:** 실적을 참가자격의 최소 금액 또는 규모·수량으로 요구하는 경우.

**위반으로 판단하는 경우:** 요구 실적 금액이 추정가격의 1배를 초과하거나, 요구 규모·수량이 해당 계약목적물 규모·수량의 1배를 초과한다.

**예외와 혼동 방지:** 정확히 1배라는 이유만으로 조문상 위반 아님. 국가 제조·용역 및 지방 규모·수량은 원칙 1/3, 필요 사유 시 최대 1배이므로 그 사유도 검토하되 1/3 초과를 곧 v3의 1배 초과로 보지 않음. 국가 공사 규모는 국가규칙25의 1배 기준. 추정가격/관급자재 포함 추정금액의 법정 예외, 부가세 기준을 확인. 시공능력평가액·평가 가점과 자격 실적을 구별.

**검토 메모:** 미확정: 항목명은 「1배수 이상」, 비고는 「사업예산 기준」이나 조문은 「1배 이내/추정가격」이다. 이 초안은 법령 우선으로 >1배/추정가격을 사용한다. 대회 라벨의 경계·분모를 확정한 것은 아니다.

## 프롬프트 연결과 32K 검사

`script.py --legal-criteria`를 지정하면 공통 기준과 현재 판단할 항목의 상세 기준·조문을 시스템 프롬프트에 추가한다. 기존 기본 프롬프트는 유지한다. 항목 분할은 기존 `--item-group-size` 옵션을 사용하며 자동 분할·원문 잘라내기는 하지 않는다.

검사 조건: Gemma 로컬 토크나이저, thinking 활성화, dev 200건, 컨텍스트 32,768. 출력 예산과 128토큰을 예약했다. 초기 입력만 검사했으므로 검색 결과·재시도까지 포함한 실행 성공을 보장하지 않는다.

| 회당 항목 수 | 총 호출 작업 수 | 최대 입력 토큰 | 출력 2,048일 때 초과 공고 | 출력 4,096일 때 초과 공고 |
|---:|---:|---:|---:|---:|
| 24 | 200 | 35,761 | 22 / 200 | 28 / 200 |
| 6 | 800 | 31,714 | 5 / 200 | 15 / 200 |
| 1 | 4,800 | 30,553 | 0 / 200 | 7 / 200 |

1항목씩/출력 2,048 설정은 초기 입력이 전부 들어가지만 최대 입력의 추가 여유가 39토큰뿐이며 호출 수가 4,800개다. 현재 thinking 기본 출력 4,096에서는 이 설정도 7건이 넘는다. 따라서 다음 실험 전에 기준 압축 또는 긴 문서 처리 방식을 정해야 한다. 위 호출 작업 수는 초기 작업 기준이며 검색·재시도는 추가 호출이다.

검증: `uv run --locked python -m unittest discover -s tests -v` — 26개 통과. 기준 24개 전체 포함, 원본 파일 SHA-256, 그룹별 기준 선택, 입력 원문 보존 및 라벨 격리를 확인했다. 법률 해석의 정답성이나 개선된 F1을 검증한 테스트는 아니다.

재생성: `uv run --locked python scripts/check_legal_criteria.py` 후 `uv run --locked python scripts/render_legal_criteria.py`.
