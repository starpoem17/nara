## 해석 범위

- 최대 초기 입력 30,228토큰.
- 문맥 예산으로 초기 검색이 제한된 공고 7건. 상세 ID는 context_check.json.
- 자율 검색과 단일 프롬프트의 첫 성능 측정이다. 검색 없는 동일 조건의 대조군을 실행하지 않아 RAG의 개선 효과를 분리할 수 없다.
- 제공 dev 예시는 실제 평가 분포를 대표하지 않는다. 대회 서버의 INT8 모델과 다른 로컬 NVFP4 결과다.
- 근거의 원문 일치는 형식 검사이며 법적 적절성 또는 대회 정성평가 점수가 아니다.
- 근거 검사: {"nonempty": 82, "invalid": 0, "positive_nonabsence_missing": 52}. 후처리에서 탈락한 근거 47개.
- 실패 예측을 0으로 대체하지 않는다. 200건 전체 ID 정합성과 CSV/추론 로그의 판정 일치를 확인했다.
- F1 분모가 0이면 0으로 처리하며 24항목 모두 평균에 포함한다.
