## 해석 범위

- 최대 초기 입력 29,252토큰. manifest.json 참조.
- 초기 문맥 예산으로 한 개 이상 그룹의 선택적 검색이 제한된 공고 3건. context_check.json 참조.
- 검색 정책과 실제 호출 수를 함께 해석한다. 검색 정책 외 비교 조건은 별도 비교 보고서에서 확인한다.
- 제공 dev 예시는 실제 평가 분포를 대표하지 않는다. 대회 서버의 INT8 모델과 다른 로컬 NVFP4 결과다.
- 근거의 원문 일치는 형식 검사이며 법적 적절성 또는 대회 정성평가 점수가 아니다.
- 근거 검사: {"nonempty": 97, "invalid": 0, "positive_nonabsence_missing": 75}. 후처리에서 탈락한 근거 74개.
- 실패 예측을 0으로 대체하지 않는다. 200건 전체 ID 정합성과 CSV/추론 로그의 판정 일치를 확인했다.
- F1 분모가 0이면 0으로 처리하며 24항목 모두 평균에 포함한다.
