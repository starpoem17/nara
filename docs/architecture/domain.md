# Domain glossary

The project reviews procurement notices against supplied review items and records each judgment with supporting evidence.

| Term | Meaning |
|---|---|
| Procurement notice (공고) | One notice, including its notice text, attached-document text, and registration metadata. |
| Review item (검토 항목) | A supplied criterion against which a procurement notice is assessed. |
| Item group (항목 그룹) | A set of review items assessed together for one procurement notice. |
| Judgment conversation (판정 대화) | The dialogue assessing one item group for one procurement notice. Its search history and judgments belong to that dialogue independently of other groups and notices. |
| Judgment (판정) | The violation decision and associated evidence for one review item in one procurement notice. |
| Evidence (근거문구) | Supporting text quoted from the procurement notice's original documents. Retrieved legal material can inform a judgment but is not evidence quoted from the notice. |

Use these terms in implementation and experiment documents. Execution state and limits are described in [Judgment conversation](judgment-conversation.md).
