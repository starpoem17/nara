# Domain glossary

| Term | Meaning |
|---|---|
| Procurement notice (공고) | One notice, including notice text, attached-document text, and registration metadata. |
| Review item (검토 항목) | A supplied criterion against which a notice is assessed. |
| Item group (항목 그룹) | Review items assessed together for one notice. |
| Judgment conversation (판정 대화) | One group's dialogue for one notice, owning its search history and judgments independently of other groups/notices. |
| Judgment (판정) | One item's violation decision and associated evidence for one notice. |
| Evidence (근거문구) | Supporting text quoted from the notice's original documents; retrieved legal text informs judgment but is not quoted notice evidence. |
| Experiment (실험) | Investigation of a stated question to support reusable conclusions or adoption/exclusion decisions. |
| Run (실행) | An identifiable execution under recorded conditions. |
| Sweep (조건 비교 실행) | One planned comparison answering a question through multiple declared conditions; recorded as one run. |
| Condition (조건) | A declared setting combination within a sweep. |
| Attempt (시도) | An execution attempt allowed by the run's predefined retry policy, retaining its own status and artifacts. |
| Follow-up run (후속 실행) | Additional execution prompted by results, receiving a new ID even when settings are unchanged. |
| Verification (검증) | A routine implementation check, recorded as maintenance evidence unless used to support experimental conclusions. |
