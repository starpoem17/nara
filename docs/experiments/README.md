# Experiments

A run investigates one question under recorded conditions. One planned comparison sweep has one ID/report with distinct conditions. Predefined internal retries remain attempts. Any additional experimental execution prompted by results has a new ID, even when settings stay the same, with bidirectional links and reasons/condition changes. Saved-only analysis is distinguished from new generation. Routine checks live in maintenance.

Start-time IDs use Asia/Seoul to seconds. The user approved `legacy_<old-name>` solely for historical runs with no recoverable actual start. Their September2026 grouping is based on historical project records, not invented start timestamps. Metadata separately records migration time. Original artifacts and withdrawal/deletion decisions remain authoritative.

Before reuse, read current judgment, scope and follow-ups in the run report. Execution success does not mean adoption. Start with the relevant problem area:
