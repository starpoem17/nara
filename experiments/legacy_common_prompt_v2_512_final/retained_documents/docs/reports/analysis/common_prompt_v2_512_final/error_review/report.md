## 1. 비교 범위와 실제 전환

두 프롬프트에서 모두 완료한 동일한 198개 공고, 4,752개 공고–항목 판정을 비교했다. 기존 실패 PPS-DEV-066·075는 제외했다. 건수는 공고 수가 아니라 공고–항목 조합 수다. 수정 모델의 전체 200개 점수를 기존 198개와 직접 비교하지 않았다.

| 변화 | 판정: 기존 → 수정 | 건수 | 서로 다른 공고 |
|---|---|---:|---:|
| 새로 발생한 미탐 | 정답 1, 1 → 0 | 24 | 21 |

정답 양성은 150개다. 기존의 참양성 55개 중 24개를 놓치고 31개를 유지했으며, 7개를 새로 맞혀 수정의 참양성은 38개다. 전체 양성 출력은 244 → 118, 정밀도 22.54% → 32.20%, 재현율 36.67% → 25.33%다. 단순히 모든 판정을 같은 방향으로 줄인 것은 아니며 새 오탐 37건도 있다.

## 6. 출력 한도·근거 후처리·인과 해석

미탐 전환 31건의 관련 그룹에서 수정 응답은 모두 첫 응답으로 정상 종료했고, 길이 제한 종료·검색은 없었다. 기존도 이 31건의 관련 응답에 길이 제한 종료는 없었으며 **049 / v1만 JSON 오류 후 정상 재시도**가 있었다. 양쪽 관련 응답의 최대 출력은 190토큰이다. 따라서 이번 새 미탐을 응답 512토큰 잘림으로 설명하는 증거는 없다. 다만 숨은 사고 과정을 관측하지 않았으므로 512 설정이 모델의 사고에 미친 일반적 영향까지 배제한다는 뜻은 아니다.

원문과 정확히 일치하지 않는 근거는 후처리에서 null로 폐기되지만 위반여부는 유지된다. 실제로 기존 01 / v1은 부정확한 인용이었어도 제한 문구가 원문에 있고, 079 / v15는 정답을 맞혔어도 지역 문구를 잘못 인용했다. **기존의 정답 일치가 곧 정확한 추론이었다고 가정하지 않았다.** 사례표에는 원시 근거와 저장 근거를 함께 기록했다.

두 실험 전체에서 검색은 0건이다. 후보의 “불명확하면 검색” 지시가 실제로 불확실성을 해소했다고 볼 수 없다. “미해결이면 0” 지시와 양성 감소는 일치하는 양상이지만, 어떤 문구가 어느 오류를 유발했는지는 각 1회 결과만으로 입증할 수 없다.

4. **기업 규모·의무 시점·예외 주체를 분리한다.** SME 전체와 소기업, 필수와 해당시, 일부 비영리 참가 허용과 전체 제한 면제를 구분한다.
5. **기준 충돌 사례를 먼저 판정한다.** 042 / v4, 09·050 / v9, 044 / v18 등을 무조건 1로 복구하는 목표를 세우면 올바른 적용 범위·동등품 인식이 다시 나빠질 수 있다.

현 후보의 Macro F1 손실 때문에 그대로 채택할 근거는 부족하지만, 오탐 감소의 구체적인 효과는 다음 프롬프트에 보존할 가치가 있다. 이번 작업은 저장 자료 분석이며 새 프롬프트 작성·추론 실험을 수행하지 않았다.
