# LJM 후보 스캐너 결과 검토

이 문서는 LJM의 `scan_candidates.py`를 변경하지 않고 dev 200개에 한 번 실행한 `scanner/candidate_v2_v8.csv`를 정답 라벨과 대조한 결과다. 플래그는 법령 위반 확정값이 아니라 상세 검토 대상을 고르는 후보 표시다. 따라서 아래 FP는 “후보로 표시됐지만 정답 라벨은 0”, FN은 “정답 라벨은 1이지만 후보로 표시되지 않음”을 뜻한다. 스캐너 결과를 Gemma 판정과 결합하지 않았다.

## 전체 수치

각 항목은 200개 전부를 평가했다. CSV에는 하나 이상의 플래그가 있는 공고만 저장되므로, CSV에 없는 공고는 해당 항목 후보 0으로 펼쳐 계산했다.

## 원본 조건이 드러나는 사례

다음 사례는 결과에서 직접 확인되는 원본 조건의 작동 예다. 법령상 정답의 원인을 새로 추정한 설명은 아니다.

1. **PPS-DEV-04 / v3 TP:** 455,000,000원 실적 요구가 배정예산 350,000,000원보다 크다. 원본이 `입찰추정가격`이 아닌 `배정예산금액`과 비교하는 조건을 그대로 보여준다.
2. **PPS-DEV-051 / v4 FN:** 대학병원 3억원 납품실적이라는 기관·금액 문구가 있어도, 지방계약 추정가격이 원본의 5억원 기준 미만이면 최종 v4 후보가 되지 않는다.
3. **PPS-DEV-162 / v5 FP:** 참가자격 구간이 길게 결합되면 수요기관 주소의 지역 토큰도 v5의 후보 신호가 될 수 있다. 스캐너 CSV는 지역 근거를 저장하지 않으므로 원출력만 보고 이 구분을 감사할 수는 없다.
4. **PPS-DEV-23 / v6 FP:** `인천광역시`처럼 광역 단위인 문구도 원본 정규식의 `시` 부분과 후속 조사 `에`가 맞아 기초지역 후보가 될 수 있다.
5. **PPS-DEV-147 / v7 FP:** 인접·확대 표현 없이도 합친 지역 블록의 지역 토큰 출현 횟수가 2회 이상이면 v7 후보가 된다. 이 횟수는 고유 지역 수가 아니다.
