# 모델에 제공한 법령의 발췌 방식

LJM의 한국어 프롬프트와 주최 측 법령패키지의 한글 원문을 사용했다. 법령을 자체 요약·번역·재작성하거나 새로운 금액·법령·누락 경고를 추가하지 않았다. 제공 패키지로 판단에 필요한 자료가 충족된다는 사용자 전제를 적용했다.

## 실제 입력과 출처 기록

- [laws.json](../../../../analysis/LJM_original_v2_v8_20260912/laws.json): 모델에 들어간 항목별 법령 문자열.
- [law_specs](../../../../analysis/LJM_original_v2_v8_20260912/law_specs/): 패키지 파일별 정확한 1-based 시작·끝 줄과 조항 위치.
- [law_provenance.json](../../../../analysis/LJM_original_v2_v8_20260912/law_provenance.json): 발췌 전 원문, 실제 포함 줄, 정리 후 문구, 파일 SHA-256, 원본 출처 헤더.
- [preflight.json](../../../../analysis/LJM_original_v2_v8_20260912/preflight.json): 실제 Gemma 토크나이저의 법령·전체 입력 토큰 수.

법령명은 출처별 한 번만 표시하고 각 발췌에 조항 위치를 붙였다. 공포·시행일과 전체 출처 URL은 원문 출처 기록에 남기고 모델 입력에 붙이지 않았다. 실제 적용 조건에 포함된 기간·날짜는 법령 문구이므로 임의로 삭제하지 않았다.

허용된 정리는 개정·신설 등 연혁 표식, CDATA 변환 찌꺼기, 빈 줄·행 끝 공백의 삭제다. 서로 다른 조항을 새 문장으로 합치거나 법적 의미를 바꾸는 축약은 하지 않았다. 실제 정리 전후 문구는 줄 단위로 추적할 수 있으며 별도 검증에서 이 삭제 규칙과 일치함을 확인했다.

## 항목별 연결 범위

| 항목 | 포함한 주요 범위 |
|---|---|
| v4 | 국가·지방 실적제한의 근거·기준, 정부 집행기준 제5조와 지방 집행기준 제1장·제4장의 특정기관·특정명칭 실적 제한 및 실적 인정 방식, 관련 고시금액 |
| v5 | 국가·지방 법률·시행령의 제한입찰 근거와 고시금액 정의, 시행규칙 제24조의 지역제한 금액·제25조의 지역 범위와 예외, 국가 고시 및 지방 집행기준 제4장 |
| v6 | v5와 연결되는 금액 근거, 일반 경쟁의 지역 범위, 국가 소액수의 대상·견적 제출·지역 범위, 지방 2인 이상 견적 제출의 지역·섬·재난 관련 조건 |
| v7 | v6의 금액·경쟁방식별 근거와 인접 시·도 허용 단서, 지방 집행기준의 인접 시·군·시·도 정의 및 소액수의 예외 |

공기업·준정부기관 고시 조항은 추출 JSON이 해당 기관 구분을 포함하고 제공 고시가 이를 별도로 규정한다는 범위에서 v4·v5에 포함했다. 후보 스캐너의 판정을 재현하거나 특정 금액을 정답으로 지시하기 위해 넣은 것이 아니다. 위 표는 독자를 위한 발췌 범위 설명이며 모델에는 제공하지 않았다.

Sol medium 에이전트 세 개가 v4, v5, v6·v7을 나누어 원문 범위를 선정했다. 추가 교차 검토에서 v4와 무관한 지방 지역제한 금액 조항을 제외하고, v6·v7에 필요한 금액 참조와 국가 소액수의 대상 조항을 보강했다. 법령 입력을 고정한 뒤 결과에 맞춰 발췌를 바꾸지 않았다.

법령 부분의 실제 토큰 수는 v4 4,049, v5 4,591, v6 6,521, v7 7,074이다. 전체 800개 입력 중 최대는 21,325토큰이며 출력 2,048토큰을 포함해 32,768 문맥 한도 안에 들어간다. 따라서 추가 추출 JSON 절단이나 요약은 하지 않았다.
